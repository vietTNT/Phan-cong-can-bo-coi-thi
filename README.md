# yêu cầu Java 17+ trở lên
# Client
## Bước 1: git clone <link-repo>
## Bước 2: cd THI_TH_LTM
## Bước 3: mvn clean compile
## Bước 4: mvn exec:java -Dexec.mainClass="ui.ClientMain"

## Tương tự cho server , mở terminal mới và chạy lệnh :  mvn exec:java -Dexec.mainClass="ui.ServerMain"

# dành cho máy chưa cài maven 
## Bước 1: git clone <link-repo>
## Bước 2: cd THI_TH_LTM
## Bước 3: .\mvnw.cmd clean compile
## Bước 4: .\mvnw.cmd exec:java -Dexec.mainClass="ui.ClientMain"

## Tương tự cho server , mở terminal mới và chạy lệnh :  .\mvnw.cmd exec:java -Dexec.mainClass="ui.ServerMain"
